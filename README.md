Sim-to-Real Transfer for Robotic Grasping via Reinforcement Learning

Master's thesis, ETH Zürich, conducted at UNSW School of Computer Science and Engineering

Overview

Trains a robotic grasping policy in simulation (MuJoCo) using SAC + Adaptive Potential Function (APF) reward shaping, then deploys it on a real Kinova Gen3 Lite arm, addressing the classic sim-to-real gap.
